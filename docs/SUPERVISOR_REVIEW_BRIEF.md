# 《石窟光谱》内容与机制评审说明

这份说明给希望从文化内容、叙事和游戏机制角度提供意见的同学/老师阅读。项目试玩地址：<https://yungang.onrender.com>

## 一句话理解项目

《石窟光谱》是一款以云冈及大同遗产网络为背景的合作研判游戏。玩家不是简单收集“正确答案”，而是要在有限行动点和不断变化的环境压力下，把来自不同地点、角色和来源的文化线索放在一起，形成一段可被讨论、可被修正的解释，再决定如何干预遗产网络。

## 玩家实际经历的核心循环

```text
观察节点与路线
  → 移动/探索取得文化证据
  → 在研究台归入「支持 / 冲突 / 待确认」
  → 形成当前解释并读取置信度、缺口与风险
  → 三选一：「立即处理 / 最小干预 / 先记录」
  → 改变项目进度、路线状态、压力、研究线索和终局档案
```

每一步都可能留下代价：移动会消耗行动点，探索会受手牌容量限制，冲突证据可能提高压力，过早干预可能推进项目但损失研究线索，先记录则更稳妥却可能错过即时修护窗口。玩家需要讨论“我们现在知道什么”“还缺什么”“这次应该承担多大风险”。

## 文化内容如何进入游戏

| 内容 | 在游戏中的作用 | 评审时可关注 |
| --- | --- | --- |
| 遗产节点 | 提供地点、任务、观察角度和行动限制 | 地点差异是否足够具体，是否像真实文化网络而非普通地图点 |
| 路线 | 表现节点之间的联系、风险、阻断与修护 | 路线治理是否让“网络”成为机制，而不是装饰线 |
| 文化证据卡 | 带有领域、来源、摘要和组合标签的研究线索 | 卡牌是否体现不同来源/立场，是否会促使玩家比较而非背答案 |
| 世界事件 | 给节点和路线施加环境压力 | 事件是否与当地语境相关，是否给玩家留下有意义的应对空间 |
| 任务与项目 | 把证据关系转成共同目标 | 完成条件是否像一个研究问题，而不是单纯集齐卡牌 |
| 三种干预 | 把解释转成价值取舍 | 三个选择是否各有合理性，是否能表达保护、推进与保留现场之间的张力 |

## 真实性与游戏化边界

- `documented` 内容用于已有来源支持的遗产信息。
- `interpretive` 内容用于研究性解释或仍需讨论的关系。
- `gameplay` 内容用于把研究过程转成可玩的行动、资源和风险。

证据组合代表“本局玩家建立了一种可讨论的解释关系”，不等同于证明了历史事实。希望评审时特别指出：哪些句子容易让玩家误以为是确定史实，哪些地方需要补充来源、限定语或研究背景。

## 目前希望获得的反馈

请优先从以下问题给意见，而不是只评价页面美术：

1. 第一次看到“支持 / 冲突 / 待确认”时，是否能理解它们在研究中分别代表什么？
2. 三种干预是否真的形成了不同价值取舍，还是只是三个奖励按钮？
3. 哪些证据卡或事件让你感到“这与云冈文化/遗产保护有关”，哪些只是换了文化名词的通用卡？
4. 节点、路线和任务之间的关系是否能被讲清楚？地图是否需要更多节点，还是当前信息已经偏多？
5. 哪些内容可能存在历史表述过满、来源不足、时代/地域混用或容易误读的问题？
6. 多人讨论时，什么信息应该公开，什么信息适合留给发现过程？
7. 一局 20–35 分钟的节奏中，哪一段最有决策感，哪一段最像重复操作？
8. 如果只能再补一组内容，你会建议增加一种证据关系、一个事件分支、一个功能节点，还是一组文化文本？为什么？

## 建议试玩方式

1. 打开试玩地址，选择默认场景开始一局；无需安装软件。
2. 先不要阅读代码或完整规则，记录第一次操作时不明白的词和按钮。
3. 尽量完成一次“探索 → 证据归类 → 形成解释 → 选择干预”。
4. 试玩后分别写下：一个觉得有文化意义的瞬间、一个觉得像普通游戏的瞬间、一个担心真实性的地方。

## 当前已知边界

- 当前不同场景会启用不同数量的节点；总数据有 24 个节点和 42 条路线，但首局不会全部同时铺开。
- 文化牌和事件文本仍需要持续进行来源审校，游戏中的组合关系不是学术结论。
- 当前优先验证核心机制和内容关系，部分节点仍复用通用视觉资产，不代表最终美术方案。
