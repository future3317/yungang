# 《石窟光谱》产品化验收清单

- [x] 服务端生成 `ActionOption`，前端不再从合法动作列表取第一项作为默认目标。
- [x] 目标选择、确认、提交锁定、revision 冲突清空旧选择、成功反馈和中文错误恢复建议。
- [x] 弃牌、交换、策略牌目标、计划标记、事件回应和角色升级均使用 pending choice 或目标选择协议。
- [x] 任务进度返回结构化 requirements，并展示来源多样性、贡献者和缺失条件。
- [x] 路线状态、事件目标、项目阶段证据和终局结果由后端结算。

- [x] SQLite WAL 与 busy timeout。

## 地图与界面

- [x] 节点使用 `layout` 字段，路线使用 `waypoints`、`roadClass`、`terrain`、`labelPosition`。
- [x] fit-to-bounds 使用当前启用节点和标签安全边距；重置和窗口尺寸变化均重新 fit。
- [x] 中央视觉引导固定在视口，玩家位置和点击聚焦跟随地图变换。
- [x] 路线可点击、键盘聚焦并打开路线检查器；地图提供地点与路线的等价键盘清单。
- [x] 拖动与点击分离，避免地图平移误触节点行动。
- [x] 移动端地图、地点、手牌为独立内容区；弹窗具备焦点锁定和 Escape 恢复焦点。
- [x] Toast 使用队列；行动取消入口使用 `role=status` 明确播报。
- [x] 原 `finishing.css` 已迁移为 `components.css`，并加入 Cascade Layers 入口。
