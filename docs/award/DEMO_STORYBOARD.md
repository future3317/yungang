# Demo storyboard

1. Landing: explain the premise and create a two-player standard journey.
2. Game shell: show the shared influence goal, roster and lit central map.
3. Focus: select a remote node and read its scene, summary and task evidence slots.
4. Market: choose a legal culture card; show the action cost before committing.
5. Repair/contribute: show the server response updating durability, evidence and timeline.
6. Event: end the round and resolve the pending choice dialog.
7. Result: show victory/defeat reasons, completed tasks and the next journey path.
