# Motion system

Motion is state communication, not decoration. Fast feedback uses `--motion-fast`; map and evidence transitions use `--motion-standard`; no spring library is required for the current shell.

- Focus scales a site node and highlights incident edges.
- Zoom uses transform only and is bounded.
- Action submission disables controls and uses a status toast.
- Dialogs provide a stable entrance and a clear close target.
- `prefers-reduced-motion: reduce` removes transitions and animations.
