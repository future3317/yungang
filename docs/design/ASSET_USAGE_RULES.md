# Phase 3 素材使用规则

## 视觉层级

- 每个视图只保留一个主视觉资产；地图主视觉是低对比度岩层底色，不使用佛像或插画作为全局底图。
- 节点图标、场景插画、证据卡和边框分别属于内容、反馈、详情和容器层，不在地图上重复铺设。
- 路线只由 SVG `path` 表达，禁止在路线层使用 PNG、拉伸位图或全局发光。

## 尺寸与比例

- 禁止对插画使用 `preserveAspectRatio="none"`。
- 装饰纹样只能使用原比例裁切、CSS `repeat`、mask 或九宫格处理。
- 核心节点 44-56px，支撑设施 32-40px，临时事件 24-32px；图标尺寸由屏幕空间控制，不随缩放无限变大。

## 审查清单

- 新增素材必须有用途、来源、尺寸和替代方案记录。
- 提交前检查 unused、duplicated、stretched 三类资源。
- 内容素材必须标记 `content_review_status`；未审校素材不得进入默认标准局。
