# 遗产节点网络 v2

## 核心循环

每位玩家回合开始拥有 3 AP。玩家在地图节点间按路线移动，或在当前位置探索、修复遗产、贡献影响力。探索会揭示节点并获得文化牌；回合结束触发一张公共事件并切换行动者。

## 设计理由

节点网络比掷骰绕圈更贴合文化遗产主题：路线表达历史连接，AP 表达有限时间，修复与贡献形成合作抉择，事件提供变化但不夺走玩家决策。所有合法动作由后端状态实时计算。

## 状态协议

游戏状态固定 `schema_version=2`，每次成功动作使 `revision` 加一。请求必须带 `player_id`、`action`、`expected_revision`，版本不一致返回 409 和 `current_state`，客户端应直接重拉并重新渲染。
