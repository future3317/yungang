# 五分钟演示脚本

1. 首页选择单人、场景和难度，展开一次高级 seed 设置并说明单人会控制两个角色。
2. 进入旅程，先展示事件预告和已锁定目标，再在规划阶段给节点放置标记。
3. 开始行动，选择移动，展示合法目标和行动前预览，确认后指出地图与当前地点变化。
4. 在地点 Inspector 查看任务步骤，从市场探索一张证据，再从手牌贡献到任务，说明证据组合的来源与领域条件。
5. 展示勘察、修护路线和策略牌目标选择；结束回合，处理事件，观察路线状态和回合摘要。
6. 完成一个项目阶段并打开升级选择，说明升级是持久触发能力而非即时奖励。
7. 演示固定 seed 的失败或胜利结算：原因、评分、项目、目标、文化档案、同 seed 重玩和返回首页。
