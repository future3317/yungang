# Release Player Journey Audit

## 本轮实际改动

- 首页从直接创建 session 改为创建正式 Lobby。
- Lobby 支持单人、本地协作、多设备房间三种模式。
- 房间创建、加入、角色、准备、开始、暂停、恢复和离开均有服务端 API。
- 房间行动通过席位 token 认证，旧 session API 仅保留兼容层。
- 多设备模式隐藏其他席位的手牌和策略牌。
- 本地协作结束回合后显示席位交接层。
- 牌库满时探索会进入弃牌选择，不再静默禁用探索。
- 结果页同时保留 `/result/:sessionId` 与旧路径兼容。

## 验证记录

- 内容校验：18 sites、30 routes、36 cards、18 events、4 scenarios。
- 后端测试：19 passed。
- 前端 TypeScript：通过。
- 前端生产构建：通过。

## 手动验收路径

1. 首页选择单人旅程，填写名字，进入 Lobby，确认自动出现第二角色。
2. 房主点亮旅程，执行移动、探索、贡献和结束回合；本地模式确认席位交接层出现。
3. 两个浏览器分别使用同一房间码加入多设备房间，确认角色不可重复、未准备不能开始。
4. 多设备中让非当前席位提交行动，确认服务端拒绝并返回恢复建议。
5. 手动把当前手牌填满后探索，确认先选择放下哪件线索，再取得新线索。
6. 完成或触发一局结算，刷新 `/result/:sessionId`，确认结果仍可读取。
