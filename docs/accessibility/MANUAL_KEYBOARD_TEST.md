# 手动键盘测试

测试环境：桌面浏览器，关闭鼠标，依次使用 Tab、Shift+Tab、Enter、Space、Escape 和方向键。

- 首页：字体设置、人数、场景、难度、seed 折叠、创建旅程和恢复旅程均可聚焦与操作。
- 游戏：焦点可到共同目标、当前角色、行动坞、地图节点、Inspector 标签和手牌。
- 地图：节点 Enter/Space 聚焦；行动模式下只确认服务端合法目标。
- 对话框：打开后焦点应进入对话框；Escape 取消非阻断预览；角色升级和事件选择不能误关闭。
- 回合：规划标记、开始行动、结束回合、事件选择和结果页按钮可完成。
- 恢复：制造 409、刷新页面和断开网络后，页面应显示中文恢复动作且不暴露错误码。

结果记录必须填写日期、浏览器、视口、操作路径、阻塞点和截图，不得用“代码看起来可行”代替实测。
