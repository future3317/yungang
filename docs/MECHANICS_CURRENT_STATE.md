# 当前机制与内容状态

此文档面向后续的机制、关卡与内容升级讨论；它描述当前实现，不把游戏布局等同于历史地理复原。

## 核心循环

每位玩家在回合开始时拥有 AP。玩家沿路线移动，或在当前位置探索、贡献、修护、准备和使用角色技能。探索从公开市场取得文化证据；贡献将证据投入地点任务；修护降低节点或路线风险；结束回合结算世界事件并切换行动者。

## 胜负与协作

标准局上限为 8 回合。当前胜利条件结合共同影响、文化领域完成度与关闭地点数量；失败由关闭地点阈值或回合耗尽触发。所有行动合法性、目标、AP 成本和 revision 冲突均由服务端决定。

## 内容规模

| 内容 | 当前数量 | 升级优先级 |
| --- | ---: | --- |
| 场景 | 4 | 让每个场景拥有不同目标、事件池和初始威胁 |
| 地点 | 18 | 补强地点任务链和相邻地点的策略关系 |
| 路线 | 30 | 增加路线状态与风险带来的可读后果 |
| 区域 | 4 | 作为地图分组与叙事镜头，不宣称历史边界 |
| 文化证据 | 36 | 增加证据组合、来源多样性和特殊用途 |
| 世界事件 | 18 | 增加预告、选择、延迟后果和场景专属事件 |
| 角色 | 4 | 强化行动节奏差异，而非单纯数值加成 |

## 前端交互约定

- 地图是主舞台；左侧行动轨道发起行动；右侧 Inspector 解释当前地点。
- Inspector 默认显示任务；探索动作时显示市场；待处理事件优先显示事件。
- 选择带目标的行动后，地图仅将合法节点和路线提升至前景；不合法节点可查看但不可提交。
- 路线、节点和区域在同一 SVG 世界坐标内缩放和平移。
- 区域 hull 与视觉坐标服务于游戏信息图，不是历史地理复原。

## 可安全修改与不可破坏项

可调整：场景可用节点、视觉坐标、区域标签、事件与卡牌内容、任务要求、视觉资产和 Inspector 文案。

不可破坏：地点 ID、既有路线端点语义、后端 `legal_actions` 作为唯一合法性来源、revision 冲突处理，以及未经核验的文化内容不得标记为 verified。
