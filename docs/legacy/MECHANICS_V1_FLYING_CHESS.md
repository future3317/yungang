# 云冈飞天棋 · 机制手册

## 游戏目标

玩家扮演来自平城、丝路、草原、中原的文明使者，沿云冈文明之路收集五类印记：

- 造像印记
- 纹样印记
- 建筑印记
- 边塞印记
- 互市印记

率先个人集齐五类印记者触发**个人胜利**；全场合计集齐五类印记且共同图卷满格者触发**共同胜利：天下大同**。

## 回合流程

每名玩家按顺序完成以下阶段：

1. **掷骰前进**：掷 1 枚六面骰，移动对应格数。
2. **触发格子**：根据落点触发格子效果。
3. **行动阶段**：选择抽 1 张文化卡，或从手牌中打出 1 张卡（最多持 3 张）。
4. **结束回合**：轮转到下一位玩家。

## 格子效果

| 图标 | 类型 | 效果 |
|---|---|---|
| 莲 | 造像格 | 获得造像印记；已拥有则图卷 +1 |
| 纹 | 纹样格 | 获得纹样印记；已拥有则图卷 +1 |
| 阁 | 建筑格 | 获得建筑印记；已拥有则图卷 +1 |
| 关 | 长城格 | 获得边塞印记；已拥有则图卷 +1 |
| 市 | 互市格 | 获得互市印记；已拥有则图卷 +1 |
| 云 | 飞天格 | 前进 2 格 |
| 沙 | 风沙格 | 消耗 2 点保护值；不足则失去 1 枚随机印记；无印记则后退 2 格 |
| 修 | 修护格 | 恢复 1 点保护值，图卷 +1；保护值已满则额外图卷 +1 |
| 贸 | 互市格 | 获得互市印记；已拥有则图卷 +1 |

## 保护值

- 团队共享资源，初始 5/10。
- 用于抵御风沙格损失。
- 草原骑行使者在风沙格只需消耗 1 点保护值。

## 遗产节点

恰好落在以下节点时触发事件：

- 云冈石窟
- 华严寺
- 善化寺
- 长城关隘
- 互市驿站
- 平城遗址

效果：共同图卷 +2，并追加节点文化日志。

## 角色能力

| 角色 | 被动能力 |
|---|---| 
| 平城工匠 | 落到造像格时额外抽 1 张文化卡 |
| 西域乐舞使者 | 落到飞天格时额外前进 1 格 |
| 草原骑行使者 | 落到长城格时额外获得 1 枚边塞印记；风沙格保护消耗减半 |
| 中原文书记官 | 落到建筑格时额外获得 1 枚建筑印记 |

## 手牌与卡牌

- 手牌上限 3 张。
- 每回合可打出 1 张手牌。
- 卡牌类型包括：造像卡、纹样卡、建筑卡、边塞卡、互市卡、行旅卡、知识卡、遗产保护卡、文明互鉴卡。
- 部分卡牌可影响其他玩家，形成互动与策略。

## 胜利条件

- **个人胜利**：任一玩家单独拥有全部五类印记。
- **共同胜利**：全场玩家合计拥有全部五类印记，且共同图卷进度达到 10/10。

## 机制审查（更新到 2026-07-25）

### 与现有实现一致的核心结论

- 项目当前“按回合轮换、掷骰前进、落点触发格子效果、抽/出牌、结束回合”的主循环可正常运行。
- 风险与协作同时存在：个人收集印记与全场共同图卷形成双目标。
- 角色能力、格子事件和卡牌效果均可通过 JSON 数据化内容驱动，便于后续迭代。

### 需要在文档中同步的关键点

- 当前前端行为是“打牌后自动结束回合”，与“动作可选项”表述相比更像 **“出牌即进入自动结算点”**。  
- 平城工匠在落造像格时会自动抽牌；再叠加手牌“可抽1张”动作后，某些回合会出现“超出1次抽牌”现象（受手牌上限约束）。
- `repair` / `storm` / `trade_fair` 等格子在文案上容易被理解为奖励格，但实际有较强状态资源联动（保护值、公用图卷）。
- 统一术语建议：规则文案中将“飞天格”明确为“航迹加速格”或“加速遗产路径格”，减少“主题误解”为字面“飞行动作”。

### 针对“是否继续做飞行棋骨架”的讨论结论

- 当前机制可达成“文化认知 + 轻博弈”的目标，但核心反馈仍偏线性前进，互动深度来自卡牌与风沙事件，属于“轻中度”策略强度。
- 如果目标是更贴合“文化路线选择/协同修复”的体验，可考虑在不改美术大框架下做“非飞行棋重构”的机制替代实验（见独立备选方案文档）。
