# 给 Claude Code 的第一段 Prompt（先审计项目）

请你完整阅读这个仓库，然后用“设计改版前审计报告”的形式输出，不要先改代码。请重点回答：

1. 当前前端入口文件在哪里？
2. 棋盘 UI、角色选择弹窗、右侧控制面板、卡牌展示面板分别由哪些 HTML 结构组成？
3. 样式分别写在哪些 CSS 文件、哪些 class 上？
4. 哪些区域目前是纯 CSS 画的，哪些区域适合替换成 PNG/SVG 资产？
5. 棋盘节点、角色头像、模块标题、卡牌边框分别应该在哪里插入图片最合适？
6. 哪些 class 命名、布局方式、DOM 结构太简陋，导致页面像 demo 而不像正式文化产品？
7. 哪些地方的颜色、圆角、阴影、字号、留白最影响高级感？
8. 当前页面有哪些“工程上容易改、但视觉收益很大”的点？请按优先级排序。
9. 如果要把界面提升为“高端文化数字产品 + 国际化优雅游戏 UI”，建议采用什么视觉系统？
10. 请输出一个明确的改版实施计划，分成：
   - P0：必须先改
   - P1：重要增强
   - P2：锦上添花

请以如下格式输出：

- 一、项目结构审计
- 二、当前 UI 问题列表
- 三、最适合接入图片资产的位置
- 四、推荐视觉系统
- 五、分阶段改版计划
- 六、需要我确认的少数问题

注意：
- 不要一上来就改代码；
- 先做审计；
- 需要明确指出文件路径、class 名、组件结构；
- 结论必须具体，不能空泛。
